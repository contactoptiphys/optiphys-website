# Premium Immersive Background Animation Upgrade

## Goal

Upgrade **only the background and animation experience** of the existing website.

Preserve the existing:

* Layout
* Content and copy
* Sections
* Navigation
* Buttons
* Typography
* Colors
* Spacing
* Responsiveness
* Branding

Do not redesign the website. Build the animation system around the existing website.

\---

## 1\. Analyze Before Changing Anything

Before modifying code:

1. Inspect the complete codebase.
2. Understand the website structure and section IDs.
3. Identify the design system, colors, typography, gradients, and existing animations.
4. Identify where the seven services appear.
5. Check for existing use of:

   * GSAP
   * ScrollTrigger
   * Framer Motion
   * Lenis
   * Three.js
   * React Three Fiber
6. Reuse existing animation/scroll systems whenever possible.

Do not introduce competing animation systems unnecessarily.

\---

## 2\. Core Creative Direction

Do **not** create:

* Tiny floating icons
* Small disconnected 3D objects
* Random spinning cubes
* Generic decorative particles
* Cheap low-poly illustrations
* Gaming environments
* Excessive cyberpunk/neon visuals

Create **one large, continuous, intelligent automation ecosystem** behind the website.

The visual story should communicate:

```text
INPUT
  ↓
AI UNDERSTANDS
  ↓
SYSTEM PROCESSES
  ↓
AUTOMATION HAPPENS
  ↓
DATA MOVES
  ↓
CUSTOMER RECEIVES RESPONSE
  ↓
BUSINESS GROWS
```

The entire page should feel like one living automation system.

\---

## 3\. Main Visual System

Create one large animated digital environment containing, when relevant:

* Flowing data streams
* Large connected nodes
* AI processing areas
* Communication pathways
* Automation pipelines
* Documents transforming into structured data
* Messages moving between systems
* Leads moving through pipelines
* WhatsApp-style communication flows
* Email filtering streams
* AI-generated content flowing into publishing systems

Do not show everything simultaneously.

The environment should evolve based on the section currently visible.

### Transition Philosophy

The ecosystem should continuously transform:

```text
Data particles
→ AI communication network
→ Lead pipeline
→ Business automation system
→ Content generation flow
→ Document/data extraction
→ Email filtering
→ WhatsApp communication
→ Connected automation ecosystem
```

Never simply hide one scene and abruptly show another.

\---

## 4\. Scale

Avoid small icons completely.

Use large compositions that:

* Occupy significant background space
* Extend beyond screen edges
* Create depth across the viewport
* Move behind multiple sections when appropriate
* Feel cinematic and immersive

Think:

**Large environments**

Not:

**Small decorative objects**

Examples:

Instead of a chatbot icon:

> Create a large communication network where messages travel toward a central AI processing structure.

Instead of a CRM icon:

> Create a large lead pipeline with data moving through qualification stages.

Instead of a PDF icon:

> Create large document-like layers that dissolve into data particles and reorganize into structured information.

# 7\. Animation Style

The animation must be:

* Extremely smooth
* Slow
* Premium
* Cinematic
* Intentional
* Subtle but impressive

Avoid:

* Fast spinning
* Sudden movement
* Aggressive bouncing
* Particle explosions
* Chaotic motion

Use:

* Smooth interpolation
* High-quality easing
* Gentle spring motion where appropriate
* Flowing movement
* Morphing
* Subtle parallax
* Depth movement
* Scroll-linked progress

The website should feel alive, not distracting.

\---

# 8\. Scroll Transitions

Use scroll progress to evolve the environment.

Prefer gradual transitions:

```text
100% Service A

80% Service A
20% Transition

50% Service A
50% Transition

20% Service A
80% Transition

100% Service B
```

Preferred transitions:

* Particles traveling into the next structure
* Connection lines reorganizing
* Large forms dissolving
* Data streams changing direction
* Components separating and reforming
* Camera moving through the environment
* Shared visual elements transforming gradually

Avoid simple fade-out/fade-in transitions.

\---

# 9\. Full-Page Experience

It may move:

* Left
* Right
* Behind content
* Partially off-screen
* Deep into the background

Different sections can have different compositions, but everything must feel like the same world.

# 14\. Mouse Interaction

Optional and subtle only.

Mouse may influence:

* Parallax
* Lighting
* Depth
* Slight orientation

Do not make objects aggressively follow the cursor.

Scroll is the primary interaction.

\---

# 15\. Layering

Required hierarchy:

```text
TOP
Navigation
Text
Buttons
Forms
Cards
Interactive UI

MIDDLE
Animated Automation Environment

BOTTOM
Existing Website Background
```

The animation must not block interaction.

Use `pointer-events: none` where appropriate.

\---

# 16\. Text Readability

Content always has priority.

When animation appears behind important text:

* Reduce brightness
* Reduce contrast
* Move objects away
* Increase depth
* Apply subtle fog/blur
* Reduce particle density

Never sacrifice readability for visual effects.

\---

# 17\. Mobile

Do not simply shrink the desktop animation.

On mobile:

* Simplify geometry
* Reduce particles
* Reduce lighting complexity
* Reduce shader complexity
* Reduce animation intensity
* Reposition large elements

Maintain the premium feeling while prioritizing performance and readability.

If WebGL performance is poor, provide a lightweight animated fallback.

\---

# 18\. Performance

Optimize aggressively:

* Lazy load heavy 3D components
* Minimize React re-renders
* Reuse geometry/materials
* Use instancing where useful
* Limit particles
* Limit expensive lights
* Optimize DPR
* Reduce effects on weaker devices
* Dispose Three.js resources correctly
* Pause/reduce animation when tab is inactive
* Respect `prefers-reduced-motion`
* Avoid unnecessary heavy GLTF assets

The animation must remain smooth on a normal laptop.
